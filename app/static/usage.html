Switch on My usage

This page costs your own smart-meter readings against your tariffs. It is off until the server has your Octopus details. Your API key stays on the server and is never sent to the browser.

Add these to /etc/agile-forecast.env (your API key is under Personal details → API access in your Octopus dashboard):

OCTOPUS_API_KEY=sk_live_...
OCTOPUS_ACCOUNT=A-1234ABCD

Then run systemctl restart agile-forecast && systemctl start agile-forecast-update.service and reload this page.
